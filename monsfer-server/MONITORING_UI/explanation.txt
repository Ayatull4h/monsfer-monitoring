# Radio Spectrum Monitoring Dashboard - Project Explanation

## Project Overview
This project is a web-based dashboard for monitoring radio spectrum data. It provides real-time visualization of spectrum data, historical analysis, and device management capabilities. The dashboard is built using Flask (Python) for the backend and Vue.js for the frontend.

## Project Structure
```
NEW_MONITORING_UI/
├── app.py                 # Main Flask application
├── requirements.txt       # Python dependencies
├── static/               # Static files
│   ├── css/
│   │   └── style.css     # Main stylesheet
│   └── js/
│       └── app.js        # Vue.js application
├── templates/            # HTML templates
│   ├── layout.html       # Base layout template
│   ├── top_menu.html     # Navigation menu
│   ├── index.html        # Main dashboard
│   └── monitoring/       # Monitoring section templates
└── data/                 # Data directory
    └── ambon/           # Ambon location data
        └── ambon_1/     # Device 1 data
            └── spectrum/ # Spectrum data files
```

## Technical Details

### Backend (Flask)
- Serves static files and templates
- Provides API endpoints for data access
- Handles file system operations for spectrum data
- Manages data formatting and delivery

### Frontend (Vue.js)
- Manages application state
- Handles user interactions
- Updates charts and visualizations
- Implements data filtering and display

### Data Structure
- Spectrum data files are stored in CSV format
- Filenames follow pattern: YYYY-MM-DD_HH-MM-SS.csv
- Data is automatically loaded based on selected date
- Time is displayed in 24-hour format
